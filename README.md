# Hyper-AutoPark-Rover (Q-ROVER)

Arduino UNO Q 기반 실물 로버로 **인지(Sense) – 판단(Plan) – 제어(Act)** 를 연결하는 스터디 프로젝트입니다.
심화 주제는 **BLE 비콘으로 목표 주차칸에 접근**하고, **후방 카메라(ArUco)와 적외선 거리센서로 후진 주차**하는 것입니다.

> **현재 상태 (2026-11-10 기준)**
> 설계와 부품 선택을 논의하는 단계입니다. 부품 구매, 조립, 구현은 **아직 확인되지 않았습니다.**
> 아래에 적힌 목표·일정·역할은 확정이 아니라 목표 또는 제안입니다.

---

## 무엇을 만드나

주차칸 5개가 있는 모형 환경에서 로버가 다음 순서로 움직입니다.

1. 정해진 통로를 직진하며 목표 칸 비콘의 ID와 RSSI(신호 세기)를 수집합니다.
2. 필터링한 RSSI로 목표 칸에 가까워졌는지 추정하고 감속합니다.
3. 회전 시작 위치를 정합니다. **(방식 미확정. 가장 큰 설계 과제입니다.)**
4. 후면이 목표 칸을 향하도록 회전합니다.
5. 후방 카메라로 목표 ArUco 마커를 확인하고 중심과 방향을 보정합니다.
6. 저속으로 후진하면서 정렬을 계속 보정합니다.
7. 후방 거리센서 값이 정지거리 이하가 되면 멈춥니다.
8. 목표 ID, 정렬, 후방 간격 조건을 확인해 완료를 판단합니다.

**선택 기능 (시간이 남으면):** 주차 금지 마커 인식, 목표를 지나쳤을 때 복귀
**범위 밖:** SLAM, VLA. BLE 비콘 구현을 C-V2X 구현이라고 부르지 않습니다.

## 시스템 구성 (후보)

```
[목표 칸] USB 전원 → 송신 XIAO ESP32S3 ──BLE 광고──▶ 수신 XIAO ESP32S3 (로버)
                                                         │ USB 시리얼
                                                         ▼
           후방 카메라 ─USB─▶  UNO Q Linux (판단 프로그램) ◀─ 후방 ToF 거리센서
                                    │ Bridge/RPC
                                    ▼
                              UNO Q MCU → 모터 드라이버 → 모터
```

| 부품 | 수량 | 용도 | 상태 |
|---|---:|---|---|
| Arduino UNO Q | 1 | Linux 판단 + MCU 모터 제어 | 보유 |
| XIAO ESP32S3 (일반형) + 외장 안테나 | 2 | 비콘 송신 1, 로버 수신 1 | 선택 방향, 구매 미확인 |
| 후방 카메라 | 1 | ArUco 인식·정렬 | 모델 미정 |
| 후방 적외선 ToF 거리센서 | 1 | 후방 거리·정지 | 모델 미정 (VL53L0X 후보) |
| 기존 전방 카메라 / 거리센서 | 각 1 | 전방 감지, 금지 마커(후순위) | 모델 미확인 |

UNO Q의 USB 포트, 허브, 전원 구성은 아직 확인하지 않았습니다.

## 폴더 구조 (예정)

담당 영역별로 폴더를 나눠서, 서로 같은 파일을 동시에 고치는 일을 줄입니다.

| 폴더 | 내용 |
|---|---|
| `beacon/` | XIAO 송신·수신 코드, RSSI 필터·추세 판단 |
| `vision/` | 후방 카메라, ArUco 검출, 중심·방향 오차 계산 |
| `sensors/` | 후방 ToF 등 거리센서 읽기 |
| `motion/` | 직진·회전·후진·정지, 이동거리·자세 보정 |
| `state_machine/` | 전체 상태 기계(탐색→접근→회전→정렬→후진→검증), 통합 |
| `experiments/` | 실험 기록(md)과 작은 로그(CSV) |
| `docs/` | 설계 문서, 모듈 간 인터페이스 정의 |

폴더는 첫 코드가 들어올 때 만듭니다.

## 모듈 간 인터페이스 (초안, 구현 전에 팀 합의 필요)

- **비콘**: ID, RSSI(dBm), 측정 시각
- **비전**: 마커 ID, 검출 여부, 좌우 오차, 방향 오차, 측정 시각 (단위·좌표계는 합의 필요)
- **거리**: 단위(mm 또는 cm 중 하나), 유효 여부, 측정 시각
- **주행**: 실제 제어 방식에 맞춰 속도·회전 명령 또는 기본 동작 명령 중에서 선택

모터 명령은 **상태 기계만** 내립니다. 카메라와 비콘 모듈은 관측값이나 보정 제안만 넘기고, 모터 명령을 직접 덮어쓰지 않습니다.

## 일정 (목표: 3주, 주마다 전반·후반 총 6회)

| 회차 | 내용 | 완료 기준 (제안) |
|---|---|---|
| 1주 전반 | 부품·환경·배치 확인, 모듈별 개별 연결 | RSSI·마커 ID·거리 출력, 기본 주행 |
| 1주 후반 | 실제 크기에서 RSSI 실험, 장착 | 비콘의 역할과 회전 위치 판단 방식 결정 |
| 2주 전반 | 목표 칸 앞에 직접 놓고 후진 주차 | 후진 주차 첫 성공 |
| 2주 후반 | 시작 위치·각도 바꾸기, 회전 연결 | 통로에서 회전한 뒤 주차까지 연결 |
| 3주 전반 | 비콘 탐색부터 접근까지 통합 | 탐색부터 주차 완료까지 성공 |
| 3주 후반 | 안정화, 반복 측정, 발표 | 반복 시연과 한계 설명 |

비콘 결과를 기다리지 않고 후진 주차를 따로 먼저 완성합니다.
